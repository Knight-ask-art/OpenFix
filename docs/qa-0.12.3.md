# 0.12.3 连续十章写作验收

## 范围与验收口径

先用本地安装的 0.12.2 和产品内 Agent 修订首章；随后使用私有数据库快照启动当前源码与已构建前端，继续真实界面写作，检验修复。每章目标约 3,000 字，验收范围 2,800–3,200（标点不计）；正文不能为满足长度机械截断。私有设定、正文、数据库、模型凭据和运行明细不进入 Git。

本文件是进行中的证据记录，不能据此宣称十章完成或长篇质量通过。

## 当前实测进度

* 首章：Mimo 修订后程序核验 **3,032 字**，已审批保存并读回。安装旧统计显示 3,360，不能据此再次削改；由此产生的多余修订已拒绝。
* 第二章：源码版 Writer 首稿实测 6,435 字，经过多次修订降至约 3,000；Reviewer 通过 source_dispatch_ids 收到候选，原 Writer 接收审稿意见后返回 2,979 字稿。人工复核拒绝该稿，四项局部修订后实测 **2,948 字**，已保留私有草稿，尚未落库。
* 外部阻塞：Mimo 流式连接发生 ReadError；切换 DeepSeek 后 ConnectError。随后检查确认用户模型网关 `127.0.0.1:3123` 未监听，已请求恢复网关。不能用这些失败尝试宣称十章验收通过。
* 验收环境问题：首次源码启动使用 Windows Proactor 导致 ZeroMQ 后台错误；改为 Selector 后后台运行正常。旧打包静态目录优先于 dist，已显式使用新 dist。环境问题与安装版本产品缺陷分别记录，不计作模型质量结论。
* 测试：收尾全量后端 **2,378 项通过，155.62 秒**。两组相关回归 126、282 项、迁移与回滚 73 项均通过（有重叠，不相加）；前端字数 71 项检查、工具消息检查、前端构建、lint 与 type-check 通过，lint/type-check 均为零警告零错误。提示词自然度回归 33 项通过。测试通过不等于十章运行验收或创作质量通过。
