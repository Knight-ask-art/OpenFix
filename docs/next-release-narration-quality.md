# 下一版本写作质量优化：叙述人称与人物指代

## 用户反馈

2026-10-14 实际长篇写作验收反馈：亲属称谓使用过密，人物姓名长期缺席，容易让人物只剩关系身份；需要同时检查第一人称与第三人称的稳定使用。

本条为下一版本待开发项，尚未实现运行时检查器。

## 约束

- 按场景确认叙述人称与 POV，区分叙述、对白及内心引语。对白里的“我”不代表第三人称叙述漂移。
- 第三人称限知可以使用“母亲”“父亲”等 POV 关系称谓，不应一律替换为姓名。
- 人物首次进入新场景、多人同场、代词指向有歧义，或者称谓长期代替人物身份时，用姓名重新建立指代。
- 指代明确的连续动作允许使用“她”“他”；避免每句重复完整姓名。
- 称谓密度只作为审稿线索，不能按固定比例替词；亲情场景的有效称谓应保留。
- Writer 提供简短约束；Reviewer 定位指代或 POV 问题；Actor 只修相关 span，保留事实、声线与叙事距离。

## 验收用例

1. 第三人称正文与第一人称对白并存，不误报。
2. 无引语边界的叙述人称漂移能定位。
3. 两名同代词人物同场，含混指代可以用姓名澄清。
4. 第一人称 POV 使用亲属称谓自然时保留。
5. 第三人称跨场后仅用关系称谓，提示重新建立姓名指代。
6. 修订不把所有“母亲”或“她”机械替成姓名，不因称谓次数判定文本质量。

## 本次运行发现的相关问题

- 完整章节扩写容易超出请求字数；仅重复提示字数不足以保证长度。
- 在叙事状态未进入实际调用上下文时，模型会给未知钥匙、人物去向和旧物来源编造解释。
- 技术题材容易把知识展示变成教程，需检查术语引入是否服务人物行动。

这些为真实候选审读发现，未经修复验收不能宣称产品已解决。

### 亲情记忆与教诲回声的重复

第27—30章候选反复使用“我妈说过”给技术判断或章末意义背书，用户指出重复。验收稿删除这些总结式引用，仅保留第27章一处与热饭关联的生活记忆。核对当前前26章没有该短语原样出现；不能据此断言此前没有同功能的重复。

- 审查相邻章节是否反复借亲人旧话解释事件、输出道理或给主角判断背书，定位具体 span 与叙事功能。
- 角色应逐步形成自己的判断；亲情可通过习惯、物件、缺席与当下反应呈现，不每次回忆都输出教诲。
- 非禁词、非固定频率：有剧情证据的关键回声可以保留，不能机械删除真实对白或有效怀念。
- 本次只是正文验收修订与待办记录，尚未实现产品级检测；已发布稿不自动覆盖。
